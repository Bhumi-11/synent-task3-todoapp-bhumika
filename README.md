## 📖 Description

This project is a simple and responsive **Todo Application** that helps users manage daily tasks efficiently.
Users can add tasks, set deadlines, and track remaining time.

---

## 🚀 Features

* Add new tasks
* Set due date for tasks
* Display remaining days
* Mark tasks as completed
* Delete tasks
* Clean and responsive UI

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
